# getcadcraft-cadcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [CadCraft (Studio)](https://github.com/getcadcraft/cadcraft), by CadCraft. The newest version lives at getcadcraft.com/use/cadcraft; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: Apache-2.0.

- Latest: `/getcadcraft-cadcraft/latest/`
- Specific version: `/getcadcraft-cadcraft/v<version>/`
- Version list: `/getcadcraft-cadcraft/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
